**KR 솔로랭크 아이언·브론즈·실버·골드 유저를 위한 경기 복기 서비스**입니다. Riot 공식 전적과 타임라인으로 먼저 볼 시각을 찾고, 포지션에 맞는 연습 행동 하나를 저장해 다음 경기 뒤 시도 여부를 돌아볼 수 있습니다. 별도로 과거 EUN 경기에서 챔피언 선택과 경기별 행동 유형을 분석하고, EUN·KR 시기별 표본을 확장하고 있습니다.

## 서비스 사용 흐름

1. **내 전적·리포트**에서 Riot ID로 최근 경기를 열고 종료 수치·팀 비교를 확인합니다. 타임라인이 있으면 **첫 15분 복기 장면 보기**에서 가장 이른 본인 데스 시각을 확인할 수 있습니다.
2. 포지션에 맞는 행동 하나를 저장합니다. 예를 들어 원딜은 첫 5분에 상대를 견제하기 전 막타를 확인합니다.
3. 다음 경기 후 **지난 연습 돌아보기**에서 시도 여부를 직접 남깁니다. **보관함**에는 리포트를 최대 50개 저장하고 같은 챔피언·포지션·패치의 두 경기 지표를 나란히 볼 수 있습니다.

행동 제안은 포지션별 규칙에 기반합니다. 로컬 모델은 설정한 경우 종료 지표로 복기 초점을 고르는 실험 기능입니다. 공식 타임라인과 이전 연습을 함께 읽어 근거와 행동을 제안하는 에이전트는 다음 개발 범위입니다. [사용·저장·실행 안내](service/README.md) · [서비스 기획과 검증 계획](docs/24_project_review.md)

## 실행 조건과 확인 방법

Python 3.11 이상을 사용합니다. 저장소 루트에서 실행합니다.

```powershell
python -m pip install -r service/requirements.txt
python -m uvicorn service.main:app --host 127.0.0.1 --port 8001
```

브라우저에서 [로컬 서비스](http://127.0.0.1:8001)를 엽니다. 공개된 참고 집계와 챔피언 도감은 바로 볼 수 있습니다. 본인 전적을 불러오려면 [Riot API 키 설정](service/README.md#공식-전적-연결)을 따릅니다.

과거 원본 없이 데이터 배치를 확인하려면 합성 예제를 실행합니다. 실제 자료의 배치 경로와 분석 재현 명령은 [데이터 파이프라인](docs/25_data_pipeline.md)과 [초기 분석 기록](docs/01_phase1_notes.md)에 있습니다.

```powershell
python -m pip install -r pipeline/requirements.txt
python scripts/run_data_pipeline.py --demo --batch-date 2026-11-17
```

## 해석과 한계

- Riot 계정의 현재 랭크는 조회 시점의 값입니다. 경기 당시 티어가 확인되지 않은 백필을 아브실골 승률이나 동티어 백분위 계산에 사용하지 않습니다.
- 타임라인은 골드·CS·데스 시각처럼 관측된 값을 제공합니다. 장면의 원인과 행동 실행 여부는 사용자가 리플레이나 자신의 기록으로 확인합니다.
- 공개 범위는 코드·집계·설계입니다. API 키·개인 식별자·원본 전적·로컬 체크포인트는 따로 보관합니다. [Riot Developer Portal](https://developer.riotgames.com/) · [공개 데이터 출처와 이용 범위](docs/11_public_data_research.md)
