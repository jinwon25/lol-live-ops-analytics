# 공식 패치 노트와 분석 결과의 사후 대조

출처: [라이엇 공식 2025.S1.3 패치 노트](https://www.leagueoflegends.com/ko-kr/news/game-updates/patch-2025-s1-3-notes/) (2025-02-04). 분석은 2026년 수행한 두 패치 표본의 사후 비교입니다. 패치 이전에 등록한 예측 기록이나 독립적인 미래 테스트가 없으므로 예측 적중률로 해석하지 않습니다.

일부 사례를 선별해 대조한 표입니다. 모든 후보·모든 패치 변경의 모집단을 기준으로 정밀도·재현율을 계산한 결과가 아닙니다. 픽률 변화와 직접 조정 방향의 일치도 패치의 인과효과를 입증하지 않습니다.

## 스웨인 후보 규칙의 의미

초기 규칙은 낮은 인기 분위와 큰 최소 표본을 동시에 요구해 후보가 0건이었습니다. 표본 수와 후보 정의의 충돌을 점검한 뒤 인기 분위·최소 표본·Wilson 하한을 분리해 후보를 만들었습니다. 이는 [규칙 설계 과정](02_phase2_notes.md)의 근거이며 사전 예측력의 증거와는 구분합니다.

## 직접 변경과 대조되지 않은 변화

신 짜오·마스터 이·야스오·트리스타나·초가스 등의 관측 변화는 직접 챔피언 변경만으로 설명되지 않습니다. 표본 오차·이용자 구성·상대 조합·아이템 변화 등 여러 원인이 가능하며, 패치 노트에 변경이 없다는 사실만으로 노이즈로 확정하지 않습니다.

후속 검증에서는 패치 이전에 후보 규칙을 고정하고, 후보 전체와 미포착 변경을 포함해 평가해야 합니다. 다중검정·게임 내 관측 의존성·시기별 표본 차이도 고려해야 합니다.
