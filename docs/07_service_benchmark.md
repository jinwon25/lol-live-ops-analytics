# 상용 서비스 참고와 개인 랭크 복기 방향

확인일: 2026-10-04. 주 사용자는 **자신의 랭크를 진지하게 복기하는 플레이어**다. 전적을 조회한 뒤 실제 장면과 다음 행동을 기록하고, 비교 가능한 내 경기들을 다시 살펴보는 흐름을 우선한다.

유료 리포트의 실제 품질이나 경쟁사 내부 모델을 검증한 비교가 아니다. 다른 서비스에 기능이 없다고 단정하지 않는다. 지역별 소개의 표본 요건이 다를 수 있어 경쟁사의 최소 경기 수를 우리 분석의 통계 기준으로 가져오지 않았다. 화면·문구·이미지를 복제하지 않았다.

## 집중할 복기 흐름

1. 완료 경기 선택: 공식 연결 또는 직접 입력. 챔피언·포지션·지역·랭크 큐·게임 버전·경기 당시 티어·일시를 확인한다.
2. 초점 하나 선택: 시야 준비, 교전 전 합류와 자원, 파밍과 귀환, 라인전 상대와 선택.
3. 사실 기록: 리플레이에서 본 시각·장면을 적는다. 경기 전체 수치와 원인 가설을 섞지 않는다.
4. 행동 기록: 다음 경기에서 확인할 조건 하나를 정한다. 반드시 성공할 운영법처럼 제시하지 않는다.
5. 다시 보기: 동일 조건의 내 경기 6개부터 최근 3개와 직전 3개를 경기 일시 순서로 비교한다. 표본 수와 KP 계산 가능한 수를 같이 표시한다.

원딜 복기에서는 특히 웨이브·귀환·교전 전 위치 선택을 확인할 수 있다. 예를 들어 DPM이 낮아졌다는 결과만으로 거리 조절 실패를 진단하지 않고, 해당 장면의 아군 합류·체력·거리와 내가 선택한 대안을 기록한다. 챔피언마다 구체적인 안전 거리나 콤보를 자동 단정하는 코칭은 아직 구현하지 않았다.

## 구현한 것과 남은 검증

- 구현: 개인 기록 보드, 4가지 복기 초점, 경기·장면·행동 저장/삭제, 조건별 기술 통계, 합성 예제 제외, 외부 참고 링크, 공식 KR 솔로듀오 API 연결 코드.
- 개인 기록은 브라우저에 최근 일시 50개를 보관한다. 같은 조건·일시는 갱신하며 예제는 수정해도 저장할 수 없다. 기존 자유 노트 10개는 별도 보존한다.
- 비교의 6경기 기준은 `3 대 3` 요약을 표시하기 위한 기준이다. 정밀도·통계적 유의성·코칭 효과를 보장하지 않는다. 티어의 세부 단계·상대 조합·승패·게임 흐름·시간 길이 차이는 아직 통제하지 않는다.
- API 코드는 모의 응답과 본인 계정의 소량 실제 조회로 검증했다. 현재 랭크를 경기 당시 티어로 자동 적용하지 않는다. 최신 KR 대규모 비교 표본과 타임라인 분석은 후속 범위다.
- 아직 없음: 타임라인 자동 사건 탐지, LLM 추론, 최신 챔피언 추천 모델, 동티어 백분위, 행동 수행 체크와 효과 추정.

후속 평가는 “한 경기에서 중요한 장면과 다음 행동을 구체적으로 기록할 수 있는가?”, “같은 조건의 기록을 다시 찾을 수 있는가?”부터 진행한다. 실제 차별성은 본인 사용 기록을 통해 확인할 가설이며 랭크 상승 성과를 미리 주장하지 않는다.
