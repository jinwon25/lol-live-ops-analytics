# 화면 구조와 자동 경기 리포트 — 2026-10-05

수동 입력 15개 항목이 기본 작업이었던 화면을 **전적 조회 → 자동 경기 리포트 → 선택 보관**으로 바꿨다. 주 메뉴는 내 전적·리포트, 보관함, 데이터 인사이트다. 수동 입력과 질문 도우미는 각 화면의 보조 기능으로 배치했다. 기존 개인 복기 기록과 초안은 보존한다.

## 구현한 흐름

1. `내 전적·리포트`에서 게임 이름·태그를 입력해 최근 KR 솔로듀오 5경기를 조회한다.
2. 서버가 각 경기의 지표·관측 사실·역할에 맞는 확인 질문을 만든다. 최신 리포트가 바로 표시되고 다른 경기를 선택할 수 있다. 경기 당시 티어 입력은 필요하지 않다.
3. GPM·DPM·분당 시야·킬 관여율·분당 CS·아군 피해 합계 대비 비중을 표시한다. 없는 CS·팀 피해와 분모 0 값은 `—`로 표시한다. 데스는 원본에 있을 때만 설명한다.
4. 이번 조회 안에서 같은 챔피언·포지션·패치의 이전 경기와 비교한다. 다른 계정의 조회나 보관한 리포트를 섞어 기준선을 만들지 않는다. 티어를 알 수 없으므로 동티어 비교로 표현하지 않는다.
5. `이 리포트 보관`은 메모 입력 없이 작동한다. 로컬에 최대 50경기를 보관하고 보관함에서 다시 열거나 삭제한다. ID·PUUID·원본 참여자 목록은 보관하지 않는다.

리포트는 `lol-match-reports-v1`, 기존 수동 복기는 `lol-ranked-reviews-v1`로 분리했다. 기존 수동 복기의 500경기·검색·수정·삭제 취소·초안·JSON 백업 기능을 유지한다. 현재 수동 복기 백업에는 자동 리포트가 포함되지 않는다. 자동 리포트용 백업은 후속 작업이다. 손상된 리포트 저장소는 새 저장으로 덮어쓰지 않는다.

수동 입력은 `직접 입력으로 복기하기`를 펼쳐 사용한다. 자동 리포트에서 수정을 선택하면 확인 가능한 수치를 폼에 옮긴다. 기존 초안이 있으면 덮어쓰지 않고 먼저 이어쓰기·삭제를 안내한다. 자동 경기 선택만으로 초안을 지우지 않는다.

## 화면 위계

큰 제목·주 동작·정렬된 6개 수치·관측 사실·복기 질문·비교 순으로 읽는다. 상세 설명과 수동 폼은 펼쳐서 읽는다. 본문은 Pretendard 14px, 제목 26~28px, 주요 수치 26~28px를 사용하고 4·8·12·16·24px 간격을 기준으로 구성했다. 네이비 메뉴와 파란 주 동작, 승리·패배의 보조 색상을 구분했다.

챔피언 탐색에는 공식 분류 필터·검색 결과 수·173개 로컬 초상을 제공한다. 공식 분류는 실제 포지션별 티어와 다르다. 최신 패치 티어표는 최신 경기 표본 확보 전까지 표시하지 않는다. 공개 경기 흐름·기존 EUN 패치 분석·근거 질문은 데이터 인사이트 안에서 접근한다.

## 검증

Python API·데이터 테스트, Node 기록 테스트, Playwright 실제 UI 흐름을 확인한다. 320·390·768·1024·1440px에서 가로 넘침을 검사하고 자동 리포트·보관·재열람·초안 보호·이미지 실패 대응을 검증한다. 화면 검증에는 합성 전적만 사용한다. 실제 계정 조회 성공을 이번 작업의 모의 검증과 혼동하지 않는다.

실력 진단·승패 원인 판정·타임라인 자동 장면 분석은 구현 범위 밖이다. 현재 리포트는 설명 가능한 종료 통계이며 로컬 LLM 실험은 [별도 모델 비교 기록](13_local_llm_research.md)으로 관리한다.
